# StockSim 市场模型与制度依据

研究日期：2026-11-07。范围：12只虚构沪市主板普通股票，人民币5000元账户，浏览器本地模拟。本文描述实现目标，参数须经实现阶段统计检查后修订；不声称已完成实盘校准，也不用于预测真实价格。

## 制度与明确简化

参考现行[上海证券交易所交易规则（2026年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)，该版本2026-07-06生效，2023版同时废止。

- 普通主板买入100股整数倍，报价最小变动0.01元；卖出不足100股的零股部分需一次卖出。T日买入不能T日卖出，T+1释放可卖。
- 每日价格范围以前收盘价计算±10%并按分四舍五入；只覆盖普通持续上市股票，排除ST、IPO和其他特殊情形。
- 价格优先、同价时间优先；成交发生在既有对手订单价。玩家与代理在同一簿中排队，后到代理不能同价插队。
- 09:30–11:30、13:00–14:57连续竞价，14:57–15:00收盘集合竞价。集合阶段不连续成交，15:00统一清算；禁止撤单。开盘集合时段为09:15–09:25，但首版从开盘后开始，不提供其操作。
- 连续竞价价格笼子：买价不高于买基准价×102%与基准价+10分的较高者；卖价不低于卖基准价×98%与基准价−10分的较低者。买基准依次取卖一、买一、最新价、前收；卖基准对称。边界按交易规则对最小报价单位处理。
- 收盘集合按最大成交量、严格优价可全部成交、同价至少一侧全部成交筛选，继而最小未成交量、候选中间价，统一成交并按价格时间优先分配。没有有效集合成交时使用规则规定的末笔前一分钟成交量加权价回退；全天无成交延续前收。
- 未成交委托当日有效；收盘失效释放冻结。T日卖股所得现金可继续买股。首版不模拟银证转账或可取资金。

2026规则已经把15:05–15:30盘后固定价格交易扩展到全部A股；本游戏明确只模拟竞价交易，未实现盘后固定价、大宗、融资融券、分红除权和公司行动。日期只跳过周末，不声称覆盖节假日与临时休市。

费用依据[上交所股票投资指南](https://one.sse.com.cn/onething/gptz/)和[财政部、税务总局2023年第39号公告](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/yhs/202308/t468451.html)。游戏券商佣金选万2.5、每张已成交委托最低5元；过户费成交额十万分之一双向；卖出印花税万5。佣金费率是游戏设置，不表示所有券商统一报价；规费含在佣金内，不再重复加收。

同一委托分多次成交时，费用按累计成交额计算后只收增量，最低5元不能每次成交重复收。买入冻结限价预算和费用预留，实际成交改良价产生差额及时释放；撤单退还未成交预算。无成交撤单不收佣金。

## 机制：价值与行为产生订单，订单产生价格

核心是异质代理的限价订单簿，不直接给最新价叠加随机数。宏观、行业、公司状态影响代理估值与风险偏好；代理下单、撤单、库存约束和新闻反应决定订单流；撮合结果决定最新价、成交量、成交额、分时和K线。

以[Chiarella、Iori（2002）](https://www.tandfonline.com/doi/abs/10.1088/1469-7688/2/5/303)与[Chiarella、Iori、Perelló（2009，2007预印本）](https://arxiv.org/abs/0711.3581)为订单驱动设计依据：基本面、趋势与噪声预期混合、异质时间视野、风险和预算约束、订单生命周期。游戏使用简化参数，不是对论文数值实验的逐行复现。

[Lux、Marchesi（1999）](https://www.nature.com/articles/17290)说明相互作用的代理可产生集群波动；[Brock、Hommes（1998）](https://www.sciencedirect.com/science/article/pii/S0165188998000116)研究策略表现影响信念选择的反馈；[Iori（2002）](https://openaccess.city.ac.uk/id/eprint/14604/)研究模仿、交易摩擦与波动/成交量的联系。这些工作为情绪持续性、趋势反馈和风险反应提供动机，不意味着有限代理自动满足全部真实市场统计性质。

### 状态与方程

每股维护潜在基本价值 `F`、短期情绪 `s`、价格趋势均线、已实现波动估计 `v`、代理现金/库存、真实限价簿。市场和行业因子共享，使同业股票有共同驱动力。

基本价值的日变化（对数）可写作：

```text
Δlog(F_i) = μ_i + βm_i M + βs_i S_sector + ε_i + J_permanent,i
s_i(t+1) = ρ s_i(t) + η_market + η_sector + η_i + J_transient,i
v_i(t+1) = λ v_i(t) + (1-λ) r_i(t)^2
log(V_agent) = log(P_i) + wF log(F_i/P_i)
             + wT clip(log(P_i/EMA_i), -0.015, 0.015)
             + wS s_i + ε_agent
```

`P`仅来自成交；`V`是代理的保留估值，不能直接写回`P`。订单方向同时考虑估值与目标库存，数量受可用现金、可卖股数、风险预算和100股手数约束。流动性代理围绕库存偏移的保留价双侧报价；主动代理用可成交限价单消耗对手簿，剩余量按限价留簿。缺少对手、涨跌停封单时允许不成交，不能为玩家凭空生成无限流动性。

每股初拟48名代理，基本面/趋势/噪声/流动性四类；每30秒tick激活3次流动性代理和5次其他代理，订单存活2–20tick。初始股票和现金一次分配，交易过程中不凭空补库存，所有代理也遵守T+1。股票总数恒定；总现金加累计手续费池恒定。

以下是**游戏初始调参范围，不是论文拟合结果**：

| 参数 | 初始范围/目的 |
|---|---|
| 宏观日创新标准差 | 0.3%–0.8%，市场共振 |
| 行业日创新标准差 | 0.4%–1.0%，板块分化 |
| 公司日创新标准差 | 0.4%–1.2%，个股差异 |

新闻分为市场、行业、公司三类；每条同时具有公开文字、受影响股票和内部永久/暂时冲击。代理在后续被随机激活时反应，响应时间并不相同，对信息解释也存在分歧。利好不保证上涨，已计价、库存与对手流动性均可改变短期走势。新闻不能在发出前对玩家公开，也不额外提供隐藏价值和未来随机数。

### 量价、K线与指数

- 每笔成交更新OHLC、股数、金额；`VWAP=成交额/成交股数`，不用平均报价冒充成交均价。
- 一分钟无成交bar可以延续上一成交价但成交量/额必须为0；午休无交易bar，不把90分钟横线伪装成交数据。
- 盘口从簿中聚合最佳五个真实价位；缺档显示空缺。撤单、过期、部分成交实时减少剩余量。
- 模拟指数以12股固定基期权重计算，名字明确为游戏指数，不冒充上证指数。

## 确定性、性能与历史

所有随机来自单个可序列化PRNG；不读取`Math.random`、实际时钟或渲染帧率。随机状态、订单序号、所有代理/账本/新闻状态入档。批量tick与逐tick结果完全一致。渲染只读快照，暂停不产生随机消费。

12×48代理、有限生命周期订单、每tick稀疏激活可以在浏览器运行。首版使用60天合成背景日线，包含市场与行业共同因子、持续波动状态、合成OHLC和成交量；这不是撮合引擎历史回放。当前交易日开盘后的5分钟则使用真实引擎预热，玩家不参与该阶段。这样避免用户启动时执行数百万次无交互的代理激活。

合成背景历史的最后收盘衔接当天前收，日线受±10%约束。不得为了漂亮日线给实时成交价直接加随机扰动。

## 验证与校准

机制测试先于观感：价格时间优先、部分成交、成交改良价、100股、价格笼子、±10%、无对手、T+1、现金复用、冻结释放、重复撤单、最低佣金不重复收、集合竞价、日终失效、跨周末、午休无成交。对所有成交验证整数价格/数量和资金股票守恒。

确定性测试覆盖相同种子和相同命令序列、批量/单步、序列化恢复。存档必须严格校验版本、有限数值、资产约束、订单引用、日历状态和RNG；坏档不得部分覆盖当前游戏。

统计评价采用[Cont（2001）](https://doi.org/10.1080/713665670)提出的经验性质作为检查方向：收益弱线性相关、厚尾、绝对收益相关、波动集聚、成交量/波动联系。不同资产和频率并非总是同时满足所有性质，参见[Revisiting Cont’s Stylized Facts for Modern Stock Markets](https://arxiv.org/abs/2311.07738)。

实现后使用多个seed的长运行，记录1/5/30分钟和日收益、`ACF(r)`、`ACF(|r|)`、峰度、量价相关、板块相关、spread分位数、零成交比例、涨跌停频率和单日换手。初步游戏验收参考日波动1%–3%、常态价差1–3分、同业相关高于跨业、绝对收益短滞后正相关；这些是自拟目标，报告实际结果，不以一条样本曲线证明统计真实性。

与纯噪声代理、关闭趋势项、关闭共同因子等消融情形比较，确认每项机制对目标性质的贡献。未完成实证校准时产品表述始终为“参考真实制度与研究的虚构模拟市场”。
