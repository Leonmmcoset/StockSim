# 稀有外部事件模型

2026-11-08。用于多人共享的虚构市场，全部计算由 Go 完成；参数是游戏设计，不是对真实股票事件的校准。算法设计、实现与测试由 GPT-6 Astra 负责。

## 频率、时点和信息边界

全市场每天最多生成一个外部事件计划，不是每股独立抽样。默认长期平均间隔 100 个游戏交易日。事件日为 D 时，D+1、D+2、D+3 三个完整交易日不生成新事件，D+4 起每个合格日用 `p=1/(100-3)=1/97` 抽样。因此相邻事件日间隔为 `3+Geometric(p)`，长期均值为 100 日；不是每 100 日必发一次。

命中后在当日尚未经过的 30 秒交易边界中均匀选择公告时间（09:30:30–11:30、13:00:30–15:00），计划与其方向、强度不公开。新开局从 09:35 启用；schema 4 升级从当前游戏时刻启用，不回放过去。首次中途日的命中概率乘以剩余有效边界数/480；收盘时启用不对当天抽样，下一交易日照常。已抽样日与计划入档，读取快照和重启均不再次抽样。

生产初始化从 `crypto/rand` 读取 256 位私有密钥，以 HMAC-SHA256(密钥,计数器) 生成独立随机流。它不使用公开 `snapshot.seed`，不消耗市场或公司 RNG。私有密钥、计数器、下一事件、实际冲击参数都不在普通快照中。确定性测试可以通过 Go Options 指定独立 EventSeed；HTTP 不提供种子、强制事件或测试触发参数。管理员整服备份原本包含内部状态，仍需视为敏感文件。

## 事件类型与公开字段

正负方向各 50%；范围为全市场 15%、行业 45%、公司 40%。公司在 12 股中等概率选取，行业由其现有行业归属确定。正事件从政策支持、技术突破、供应链修复中等概率选择；负事件从政策收紧、灾害冲击、供应链中断中等概率选择。

公开新闻复用 `id/time/headline/body/scope/symbols/impact`，新增：

```ts
kind: 'external'
event: {
  category: 'policy' | 'disaster' | 'supply-chain' | 'technology';
  severity: 'major' | 'extreme';
}
```

`major` 占 80%，隐藏的有符号对数信念冲击幅度为 0.12–0.22；`extreme` 占 20%，幅度为 0.22–0.35。这不是承诺的涨跌幅。客户端不显示预测收益、倒计时或未来冲击。

## 公告和交易者响应

时钟推进一个 tick 后，先完成该 tick 撮合、财报和收盘清算，再发布到期事件新闻并更新隐藏信念。公告时不修改 last、K 线、订单簿、现金、持仓或公司财务报表；下一 tick 被激活的交易者才按照新的信念重新报价。公告出现在 15:00 时，交易反应从下一日开始。

设有符号冲击为 J：

- 长期估值信念：`F ← F × exp(0.6 J)`；事件新增的估值偏离限制在最新价的 0.5–2 倍。若原有信念已超出该区间，向外的事件不再扩大偏离，向内的事件仍可修正，避免限幅把利好反转成负向信号。
- 公告情绪：`sentiment ← clip(sentiment + 0.04 J, -0.035, 0.035)`，之后仍按原模型衰减。
- 暂态以剩余 `0.4 J` 为基数映射到情绪、方向信号和不确定性；这些不同量纲的响应不能相加当作收益率。
- 暂态衰减：`d(age)=2^(-age/240)`，age 为公告之后的实际交易 tick 数；240 tick=120 分钟交易时间=半交易日。1440 tick（3 个交易日）后暂态完全移除；午休、收盘等待和暂停不消耗 tick。
- 额外方向信号为 `0.10 J × d`；不同策略权重为基本面 0.8、趋势 0.6、噪声 1.0，并乘以该交易者原有 bias 派生的有界敏感度（0.5–1.5）。不会新增市场 RNG 消耗。
- 不确定性为 `abs(J)/0.35 × d`，增加已有噪声项宽度。流动性代理可扩大价差、缩小挂单量，保留价随方向信号偏移；价格偏移限制在最新价的 ±0.8%。所有申报仍经过原有预算、库存、T+1、价格笼子和 ±10% 日涨跌停检查。

每个事件最多产生一次公告和一次长期信念变更。冷却长度使上一事件暂态在下一可发生日之前结束，不累积无限暂态；长期信念新增偏离有界。价格仍完全来自真实撮合，正消息不保证上涨，重大事件也不保证涨跌停。

## 保存、迁移与校验

输出 schema 5，保留现有交易状态并新增私有 Events 状态。schema 4 必须先通过原完整结构、账本、财报、复盘校验，确认没有伪装的新字段后才生成私有事件密钥并安排当前剩余时段；不重写市场 RNG、公司 RNG、资金或旧新闻。后端启动应将迁移后的 schema 5 原子保存，避免下一次事务前再次重启而重新生成密钥。

schema 5 的必需事件字段缺失或 null 应拒绝；计划必须属于当前已调度日且未发布，时点与 tick 偏移一致。历史公告按时间与序号排序、范围/证券/类型/方向/强度一致，冷却和有效期受校验；公开新闻的外部事件元信息必须能匹配已公开事件记录。保存恢复不会重新扣款或重复应用冲击。

## 依据与验证范围

Merton (1976) 的 [论文 DOI](https://doi.org/10.1016/0304-405X(76)90022-2) 是不连续收益/跳跃事件模型的经典来源；此次 MIT 原稿访问返回限流，未将未读取全文当作系数依据。本游戏使用低频事件到达的概念，不照搬其直接价格跳跃或期权定价公式。

Cont、Kukanov、Stoikov 的[作者预印本](https://arxiv.org/abs/1011.6402)研究美国股票的订单流不平衡与价格变动，并发现冲击关系受市场深度影响。本游戏据此保持“消息改变订单，撮合产生价格”的分层；不把论文结果直接当成 A 股或本游戏的实证校准。

验证包括独立随机流、未发生时原 golden 一致、公告不直接改价或改钱、后续真实撮合的有界冲击、作用范围、暂态衰减、多人共享、批量/逐步/恢复一致、schema 4 严格迁移与坏状态拒绝。频率采用大量仅调度器样本，不运行数万完整市场日。实际样本统计与可复现演示样本如下。


## 实测结果与演示样本

使用 `event-frequency-0` 至 `event-frequency-9` 十个固定私有测试种子，各运行 100000 个完整调度日，不执行 NPC 撮合，共 100 万调度日：

| 指标 | 实测 |
| --- | ---: |
| 事件总数 | 9945 |
| 相邻事件日平均间隔 | 100.5366 日 |
| 公司 / 行业 / 全市场 | 3973 / 4517 / 1455 |
| 正 / 负 | 5013 / 4932 |
| major / extreme | 7977 / 1968 |
| 冷却违规（间隔小于4日） | 0 |

该固定样本耗时约 0.67 秒，仅证明调度器频率接近配置；不是市场波动的统计校准。回归允许均值 100±4 日，方向/范围/级别比例相对配置差值不超过 2.5 个百分点。

强冲击撮合样本使用固定市场种子 `external-market`，分别在公司、行业、全市场范围施加 ±0.34 的极端政策信念冲击。在公告之后 90 tick（45 分钟交易时间），600301 相对**公告时成交价**分别变化 +10.363% / −9.690%，新增成交 189500 / 175100 股；六个场景均经真实撮合，所有逐笔成交及最新价仍在以前收为基准的 ±10% 日价格范围内。公告时价格略低于前收，因此从公告价到涨停的比例可以超过 10%。这是有意选择的强冲击能力样本，不代表每个随机事件都会达到该幅度或命中涨跌停。

离线真实服务演示使用独立测试 `EventSeed="external-ui-12689"`、公开市场 seed `external-ui-market`、historyDays=0。初始 2026-11-09 09:35；计划在当天 **09:37:00**（Unix 毫秒 1794188220000）自然发布消费行业技术突破：600201、600202，positive、extreme。默认 1× 约四个现实秒后到达该时点。演示是已知私有测试种子的假数据，生产不使用这个种子。

仅 Go 测试可生成离线 fixture（在 `server` 目录运行），可给临时数据库的真实用户 ID：

```bash
STOCKSIM_EVENT_FIXTURE_PATH=/tmp/stocksim-event-demo.json STOCKSIM_EVENT_FIXTURE_SEED=external-ui-12689 STOCKSIM_EVENT_PLAYER_IDS=id1,id2 go test ./internal/market -run '^TestExternalEventUIFixture$' -count=1 -v
```

该命令只写指定的测试文件；没有新增生产 HTTP 触发接口。schema 4 真实三玩家备份已与旧版本生成的完整公开快照和原内部字段进行对照，迁移未改市场、账户、委托、报表或复盘；应用启动写回后，暂停重启不会重新抽取私有密钥。

独立审查发现并已修复两项持久化边界：匿名嵌入事件字段必须检查存在性（尤其合法零值 dayIndex）；仍在 100 条新闻窗口内的事件记录必须有对应公开公告。合法的旧公告自然裁剪可以缺席，但不能删掉刚发布公告后继续保留其隐藏交易反应。
