# 财报与旧存档审查

审查范围：财报生成、披露调度与存档校验；以当前工作区的 alpha 实现为准。未发现可复现的 P1/P2 问题。

- 财报实际值在披露时生成，公开预期由已有报告计算；检查了发布时间及下次披露时间。七个交易日（含跨周）在开盘及上午检查 v2 导出再导入与披露时间，覆盖首日 10:00 披露点，未见未来披露或恢复失败。现有测试覆盖披露后不重复及恢复后确定性。
- 资产等于负债加权益，也等于现金、固定资产和营运资本之和；利润、经营现金流、资本开支及每股指标的计算与存档校验口径一致。PE 使用最近四期净利润，EPS 为最新单期每股收益。
- 用真实旧存档恢复后，账户与旧基线一致；除新增公司数据外，旧引擎状态结构比较一致，包括账户、订单与随机数状态。另检查七个交易日不同时间的模拟旧档迁移，旧状态均保持一致。
- v2 校验检查财报算式、披露日期、期间顺序、预期以及公告关联；现有财报测试覆盖损坏数据与重复期间。财报周期使用五个交易日，是压缩的游戏模拟；参数未做现实公司或会计准则校准。

审查不能证明所有随机种子、长期周期和所有损坏输入均已覆盖。
