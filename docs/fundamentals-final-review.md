# F10 与财报最终审查

审查范围：财报入口与报告定位、公司切换和键盘交互、财务单位和亏损显示、存档迁移与拒绝无效存档。审查结合代码及现有验证证据；未对产品代码作修改。

## 结论

未发现尚未解决的 P1/P2 问题。

此前发现财报快讯标题对亏损报告使用“盈利不及预期”，可能误导读者。现已改为“净利润超出预期 / 不及预期 / 符合预期”，表述适用于正负净利润。新增回归测试使用真实模拟产生的瑞宁生物第 5 期亏损报告，检查其负向预期差及标题；针对该用例运行 Vitest，1 项通过。

PE 显示已复核：公司概况与同行比较均在滚动四期净利润为负时显示“亏损”，零利润显示“—”；PB 非正净资产显示“—”，与页面说明一致。

此前验证证据包括 42 项单元测试及构建通过，以及浏览器核验四个 F10 页面、同行切换、10:00 披露和新闻跳转、真实旧版存档持仓及刷新恢复。本次复审未重复运行全量测试或浏览器验证。
