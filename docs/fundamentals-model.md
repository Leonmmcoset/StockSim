# 公司经营、模拟季报与预期差模型

本模型用于 12 家虚构公司的本地股票模拟，不使用真实行情、真实财报或运行时 LLM。参数为可解释的教学与游戏参数，**没有经过真实市场校准**，不构成估值或交易建议。金融公司也使用下述统一简化经营模型，不实现银行资产分类、证券监管报表或行业会计规则。

## 时间与信息边界

- **5 个交易日约一模拟季度**。公司首次发布时间依股票列表错峰在第 1–5 个可体验交易日的 10:00；新游戏从首日 09:35 开始，首批在当日 10:00 发布。之后每家公司隔 5 个交易日发布。
- 日历按周一至周五推进，不接入法定节假日，也不是现实法定财报披露日历。每份报告称“第 N 期（模拟季报）”，不将未来自然季度写成已发生的经营事实。
- 初始四期是明确标记 `synthetic: true` 的合成历史，每期相隔 5 个模拟交易日，发布时间均早于当前时点。后续保存最近 24 期，按最新在前排列。
- `pending` 只保存发布日期、期次和公开预期。实际经营随机扰动在时钟到达发布日期时才抽样，实际报表也只在那一刻生成。快照只暴露已发布报表及下期公开预期，不包含隐藏估值、公司 RNG、成本参数或未来实际盈利。
- `step()` 完成本次 30 秒推进后检查公告时点。到 10:00 的快照即可看到公告；财报更新的信念从下一次交易决策开始进入订单。恢复游戏不会提前发布或重复发布。旧档在 10:00 后迁入时，首批安排在下一交易日，避免倒发新公告。

## 单位与报表恒等式

所有营收、损益、现金流、资产负债合计均以**整数分**保存；股份单位是股，固定等于该股票现有总股份（当前 4,800,000 股）。EPS/BPS 是分/股，保留比值精度，界面除以 100 显示元/股。所有 `Pct` 是百分比点（例如 5 表示 5%）。公司现金与交易所钱包现金分属两个经济系统，不向玩家或背景交易者账户注入经营所得。

经营流量按一期生成，资产负债表保存期末余额。模型无新增融资、偿还本金、分红、增发、回购、除权、少数股东、递延税项或其他综合收益；全部利润视为普通股股东收益并留存。

| 项目 | 计算关系 |
| --- | --- |
| 税前利润 | 营收 − 经营成本 − 折旧 − 利息 |
| 所得税 | max(0, round(税前利润 × 25%)) |
| 净利润 | 税前利润 − 所得税 |
| 经营现金流 | 净利润 + 折旧 − 营运资本增加额 |
| 投资现金流 | −资本开支 |
| 期末现金 | 上期现金 + 经营现金流 − 资本开支 |
| 期末固定资产 | 上期固定资产 + 资本开支 − 折旧 |
| 期末营运资本 | 上期营运资本 + 营运资本增加额 |
| 总资产 | 现金 + 固定资产 + 营运资本 |
| 负债 | 保持原本金不变，利息计入损益和经营现金流 |
| 权益 | 总资产 − 负债 = 上期权益 + 本期净利润 |

营运资本是简化的非现金经营净资产桶（应收/存货等净额）；负债桶为恒定有息负债。这里不声称完整实现 IAS 7、IFRS 18 或中国企业会计准则。

每期经营趋势遵循有界均值回复过程；营收受公司自身趋势和新扰动影响，成本率受公司固定经营结构和当期成本扰动影响。各公司初始目标净利率不同，瑞宁生物带有较高研发投入和初始亏损情形。折旧为上期固定资产的 1.5%，利息为负债的 0.3%；营运资本目标为营收的 16%，正常资本开支为折旧的 120%。现金紧张时，经营成本、营运资本投入与资本开支均受可支付能力约束：这是支出收缩规则，不是凭空融资，也不模拟完整破产清算。

## 预期、增长与估值口径

下期共识仅由已公开历史构造：营收预期将最近一期营收乘以 `1 + 0.5 × 有界营收环比 + 1.5%`；盈利预期是最近一期净利加上其绝对值乘以 `0.5 × 有界盈利环比 + 乐观偏差`。华川银行乐观偏差为 12%，其他公司为 1.5%。该公开共识可以偏离未来实际，公司不预先知道未来扰动。上一期利润非正时，盈利趋势项设为零；这不改变已公开实际亏损。

- 营收与净利增长均为**环比**。`(本期 / 上期 − 1) × 100`；上期基数为零或负时返回 `null`，不把扭亏或负数相除包装成普通增长率。最初第 1 期没有公开对比基数，增长也为 `null`。
- 盈利预期差 = `(实际净利 − 此前预期净利) / max(abs(此前预期净利), 此前预期营收 × 1%) × 100`。地板项防止接近零的净利预期造成无穷值；这是一项明确披露的模拟口径，不是文献中的标准化意外盈利 SUE。营收预期差使用同一公式，而正营收预期自然成为分母。
- 公告同时保存实际、此前预期和预期差；不会在发布后用实际值改写先前共识。默认种子 `stock-sim-2026` 的首份华川银行新报告可观察到净利润环比约 +6.42% 而盈利预期差约 −5.16%，说明“利润增长”和“超出预期”不同。
- 动态市值 = 最新成交价 × 固定股份；PE 使用市值 / 最近 4 期净利合计，合计 <= 0 时为 `null`。界面区分亏损和零盈利，不显示负 PE。
- PB = 市值 / 最新权益；权益 <= 0 时为 `null`。EPS 为本期净利 / 股份；BPS 为最新权益 / 股份。
- ROE 为最近 4 期净利 / **最新期末权益** × 100，是简化口径，不是平均净资产 ROE；权益 <= 0 时为 `null`。负债率为最新负债 / 总资产 × 100。
- 同行由既有行业分类确定，展示同一口径数据，不另造行业平均或“合理价值”。

## 财报如何影响价格

只在公告已公开后调用 `applyEarningsSignal`：盈利预期差比例截断到 ±0.8，营收预期差截断到 ±0.3，然后

```text
F_new = F_old × exp(0.055 × 盈利预期差比例 + 0.025 × 营收预期差比例)
s_new = clamp(s_old + 0.018 × 盈利预期差比例 + 0.006 × 营收预期差比例, −0.035, +0.035)
```

`F` 是原有交易者的隐藏估值信念，`s` 是原有情绪信号。基本面交易者、趋势交易者、噪声交易者与做市者沿用不同权重、仓位约束、随机决策和限价单撮合。财报代码**不写 `last`、成交价、K 线或交易账户**。正预期差只是提高相关信念，不能保证价格上涨；盈利增加但低于预期也可能产生负向信号。普通新闻、宏观和行业扰动仍然存在。

这采用“实际减预期”作为消息增量的研究思想，不复制论文的实证模型，不保证产生真实市场的公告后漂移统计量。持续的估值信念和逐渐衰减的情绪提供后续订单影响，实际成交结果由市场决定。

## 随机性与存档

市场保留原来的 RNG；各公司使用 `hashSeed(seed + ':company:' + symbol)` 派生独立、可序列化 RNG。公司初始化、迁移和报表生成都不会抽取消耗市场 RNG。相同 seed、时钟推进、操作与存档恢复得到相同结果；分批 `step(n)` 与 n 次 `step()` 等价。

新存档为 `schemaVersion: 2`。导入 v1 先执行原有钱包、资金总额、股份、冻结资金/股份、订单、费用与行情时间校验，成功后才补齐公司状态。不会清空账户、持仓、订单、成交或新闻，也不会改原 RNG/seq/tick。v2 额外校验报表恒等式、跨期资产与现金勾稽、股数、增长率、预期差、可重建的历史共识、未来计划、披露时点以及公告对应关系；校验失败不覆盖原进度。

## 研究依据与局限

1. Ball, R. & Brown, P. (1968), *An Empirical Evaluation of Accounting Income Numbers*, Journal of Accounting Research 6(2), 159–178，尤其第 161 页的“预期与非预期收益变化”讨论。本实现从中采用“相对既有预期的盈利变化才是新增信息”的设计思想，并未复刻其 OLS 收益预测与事件研究。原始论文：[JSTOR/DOI](https://doi.org/10.2307/2490232)；已查阅的[原论文扫描件](https://dallenwapty.com/coursematerial/investmentv/ballandbrown1968.pdf)。
2. Bernard, V. L. & Thomas, J. K. (1989), *Post-Earnings-Announcement Drift: Delayed Price Response or Risk Premium?*, Journal of Accounting Research 27, 1–36，[原论文入口](https://www.jstor.org/stable/2491062)。本轮可核对原论文标识，入口未提供可读正文，因此不以它背书本实现系数或任何量化结论；仅列作公告后反应方向的后续研究背景。
3. IFRS Foundation，[IAS 7 — Statement of Cash Flows](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows/)。其现金流分类与间接法调整非现金项目/应计项目的原则，为这里的现金流桥接提供概念依据；本模型主动简化经营、投资与融资分类，不声称完整准则合规。
4. IFRS Foundation，[IAS 33 — Earnings per Share](https://www.ifrs.org/issued-standards/list-of-standards/ias-33-earnings-per-share/)。EPS 的利润归属与加权平均普通股口径提供概念依据；本模型没有股份变化或潜在稀释，故固定总股数即本期加权平均股数，不另模拟稀释 EPS。
