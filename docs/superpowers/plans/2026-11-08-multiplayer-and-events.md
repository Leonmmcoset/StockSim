# 多人共享市场与稀有事件实现计划

**目标：** Go 权威多人市场与账户，完成后添加低概率高影响外部事件。
**架构：** Go engine + 串行事务服务 + SQLite + HTTP/SSE；React 在线终端。每位子代理有独立文件所有权，root 集成、验证、Git 提交。
**规格：** `docs/superpowers/specs/2026-11-08-multiplayer-design.md`，API：`docs/multiplayer-api.md`。

## 审查重点

- 第一个用户注册并发时只能有一个管理员，市场/用户不可部分提交。
- 他人订单、仓位、密码与未来财报不可通过HTTP/SSE/备份越权泄露。
- 提交超时重试和并发取消不重复扣款，落盘失败不改变 live 状态。
- 多人双边交易后现金/股份/费用/复盘恒等式以及新增玩家无市场RNG扰动。
- 服务器无人值守午休/收盘/周末继续；人工暂停与重启状态保存；事件不会绕过涨跌停、泄露未来或被重载重复发布。
