# 稀有外部事件实现计划

> 执行方式：由当前 Astra 算法代理内联实施，root 负责独立复审和提交；不再拆分算法代理。

**目标：** 以全市场均值 100 日的私有随机事件影响真实订单流，保持多人市场与旧档恢复。
**架构：** 私有 HMAC 计数流与按日调度，公告后隐藏信念和有界暂态响应，schema 5 保存与 schema 4 严格迁移。
**技术：** Go 标准库 crypto/rand、crypto/hmac、crypto/sha256，无新依赖。
**规格：** `docs/external-events-model.md`。

## 边界与审查重点

- 不改认证、HTTP、管理员权限或撮合规则；普通 snapshot 只新增公开新闻元信息。
- 旧公开 seed 不可预测事件；事件调度不消耗原 RNG；未来计划不得泄露。
- 公告在 tick 撮合后发布，下 tick 才有价格反应；午休/暂停不衰减。
- schema 4 先严格验证再补状态；同版本缺字段必须拒绝；升级后需服务端启动落盘。
- 发生概率是全市场一次/日，含 3 日冷却后的均值 100 日；统计验证只运行调度器。
