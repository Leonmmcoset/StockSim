# 共享市场与 Go 服务端设计

## 用户要求与确定语义

- 现有黑色炒股终端改为前后端分离；Go 服务端独占行情计算、撮合、账户与存档，浏览器只展示与提交指令。
- 所有玩家看到相同的股票、价格、盘口、财报、新闻与游戏时间；独立账户均以 500000 分（5000 元）起手，玩家订单进入同一个订单簿，可以相互成交。
- 原子注册的首位用户是管理员，也有普通玩家账户；后续用户是普通玩家。角色由服务端判定，客户端不可指定。
- 用户最终选择游戏时间，而非现实时间。默认 1× 为每现实秒推进 30 个游戏秒；仅管理员可暂停/继续、设 1/4/16/64×、跳午休及下一日。所有人的时间同步。
- 用户明确要求休市自动衔接。运行时午休停留 3 个服务器秒，收盘停留 5 秒后自动开启下一交易日并跳过周末；人工暂停冻结自动衔接计数。后台无人在线仍运行。停机不补算，重启按保存的时间、速度与状态继续。
- 多人功能实现、验证与提交之后，再实现低概率、大影响的外部事件，先公告、再通过交易者和撮合影响行情，遵守涨跌停。
- 算法仅由 GPT-6 Astra 编写；其余子代理用 GPT-6.1 Sol / Terra。每个可运行功能分别 Git 提交，最后同步 GitHub。

## 技术与边界（实现决定）

React/TypeScript/ECharts/Zustand 沿用。Go 独立模块 `server`（模块名 `stocksim/server`），标准 net/http、纯 Go SQLite 驱动 modernc.org/sqlite、Argon2id。服务器可托管生产 dist，Vite 开发环境代理 /api；提供 Docker 及本地启动说明。没有 Node 计算子进程或外部模型依赖。

Astra 将 TS 市场、账本、基本面、财报与复盘移植为 Go；原 TS 引擎保留供回归对照，不在在线前端运行。整数金额分，公开 JSON 字段与已有 MarketSnapshot 一致。每个玩家独立订单、成交、成本、费用、已实现损益和复盘；公开 API 不暴露他人账户、内部 NPC 状态或未来财报。

单个服务拥有引擎并串行处理市场写入。变更在候选引擎执行，SQLite 事务成功后才替换 live 引擎并广播；持久化失败不能留下未保存资金变动或重复广播。数据库保存用户、密码哈希、会话、全市场、运行配置及幂等记录。已有存档损坏必须明确失败，不能偷偷新开局覆盖。

本地历史存档保持原样，仅供下载备份，不允许导入共享市场注资。在线断线保留最后行情并明显标记过期、禁用交易，重连获取权威状态；不降级为本地市场。

## 认证、管理与并发

用户名密码注册登录；随机会话 Cookie 为 HttpOnly/SameSite，数据库只存 token 哈希；HTTPS 时 Secure。修改操作校验同源、CSRF、JSON 类型、字段与体积；会话过期、登出或封禁后不能继续请求/订阅。密码 KDF 并发和认证频率有界。

首位管理员判定、用户创建、5000 元账户注资、市场保存和登录会话在同一事务提交。管理员可列出用户、禁用/解禁普通用户、开关注册、控制全服时钟并导出一致的整服备份；不能封禁自己/管理员。封禁撤销会话并禁止继续登录/交易，原有挂单继续按既定规则撮合（界面说明）。备份包含敏感密码哈希，省略会话和幂等缓存，不提供任意整服导入覆盖接口。

下单/撤单带 Idempotency-Key，服务端按用户与 key 原子保存响应及输入哈希。相同操作重试返回原响应，key 配不同内容拒绝；不能因超时重复成交。幂等保留 7 日，前端超时保留同 key 安全重试，绝不自动新 key 重下。

## 公开 HTTP 契约

精确类型/路由见 `docs/multiplayer-api.md`；算法 Go 接口见 `docs/go-engine-contract.md`。

SSE 推送用户自己的快照，慢连接丢旧快照取最新而不阻塞市场。公共行情全员一致，私有部分按会话裁剪。普通快照的 review.points 为空数组，日报保留；完整曲线仅在复盘选区端点请求，避免每秒对所有人推送 30 日历史。

前端异步命令和预览有 pending 与过期响应保护；错误/连接状态可见。登录页说明首位用户为管理员；测试只用临时数据库，不抢占正式预览的首管理员。原终端保留账户、财报与复盘布局。

## 第二阶段：稀有外部事件

多人阶段先独立完成。Astra 另行明确概率、强度、持续/衰减、影响范围、公开事件、独立 PRNG、保存恢复、可控测试注入，以及跨多种子的频率检查。不开管理员随意改价的捷径，不提前泄露事件；不承诺每次事件必然涨跌停。参数写入模型文档，统计和回归通过后独立提交。

## 验收重点

首管理员竞态；两人相同报价且各自隐私；真实人对人成交双边费用与资金股份守恒；T+1、部分成交、撤单、复盘和财报；断线/重复请求/服务器重启；保存失败回滚；普通玩家越权与跨站请求；无人在线、午休/收盘/周末自动衔接及人工暂停；罕见事件发生率与保存恢复一致。使用 Go race、Go 集成测试、既有 Vitest、前端异步测试、生产构建及真实浏览器双会话检查。验证发现缺陷修复后才合入，不宣称证明软件永远无 bug。
