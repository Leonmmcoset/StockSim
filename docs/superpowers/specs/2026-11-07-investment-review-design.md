# 资产曲线与每日投资复盘

## 用户确认

- 先做资产曲线与每日复盘，沿用现有黑底终端，在底部增加「投资复盘」页签。
- 统计算法继续由 GPT-6 Astra 实现，其他子代理为 GPT-6.1 Sol / Terra。
- 原有模拟行情、公司财报、交易规则与资金账本保持；按功能提交。

## 本轮实现选择

- 根据真实账户状态采样总资产、现金、股票市值、仓位与同期股海指数。采集不消耗随机数，不改变市场、成交或账户。
- 使用有限历史（最近 30 个交易日左右），控制存档体积。新开局从玩家可以操作时开始；旧存档从升级/导入时开始，不伪造旧曲线。
- 可选单日、最近若干交易日及全部保留区间；账户与指数按同一时点基线归一化，区间指标与图表范围一致。
- 盘中报告标为进行中；收盘后定稿并可回看。当日收益、同期基准、超额收益、手续费、成交笔数/金额、已实现盈亏、浮盈变化和观察最大回撤均由引擎返回。
- 净盈亏已包含费用。已实现盈亏增量加浮盈变化等于净盈亏；若展示费用前结果，必须通过明确的费用加回口径，不能再扣一次费用。
- 旧档的部分交易日明确显示采集开始时间和覆盖不完整提示；不将升级前成交或费用当成新采集区间发生。
- 本轮不实现完整买卖点回放、新闻事件时间轴、年化夏普、胜率或交易建议。

## 界面

底部原有账户标签增加「投资复盘」。选中时，主工作区展示全宽复盘面板，底部保留标签和全局资产摘要；原看盘区域隐藏但不卸载，切回后保留委托草稿、股票与 F10 状态。

复盘面板提供日选择、区间切换、资产/收益对比/仓位图与统计摘要，自己滚动和处理窄屏，不改全局主题。只有一个采样点时提示继续运行，不画假历史。

## 存档

引擎存档升级 schema 3，继续导入 1 和 2；外层 GameSave 仍为版本 1，严格接受引擎 1/2/3。先验证旧账本和公司状态，再初始化复盘基线；保持旧资金、持仓、订单、时钟、市场及公司随机数状态。

新档验证点位时间、金额、顺序、日结与当前账户一致性，以及派生指标，禁止未来点、非有限值和篡改摘要覆盖 live 状态。

## 验收

1. 空仓、新成交、挂单冻结/撤单与手续费在曲线和汇总中口径正确。
2. 日结只发生一次，跨日与保存恢复不重复记账，采样不影响交易结果或随机数。
3. 同期基准和最大回撤由明确的观测数据计算，区间选择后的指标与曲线一致。
4. 真实 v1/v2 旧档迁移保留全部原状态，部分日标注清楚；损坏历史拒绝导入。
5. 1440×900 和 390×844 可用；复盘开关不丢交易草稿，原 F10/交易仍可使用。
6. 完整测试、构建、独立审查与真实浏览器验证通过；记录方法、限制和存储上限。
