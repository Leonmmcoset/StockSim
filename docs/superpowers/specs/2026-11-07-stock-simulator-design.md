# 股海 StockSim：A 股拟真模拟终端

## 用户已确定

- HTML5 浏览器股票模拟游戏，玩家以人民币 **5,000 元**起步。
- 真实 A 股交易制度、虚构公司、自动生成行情、可加速模拟时间。
- **传统黑底红绿字，尽量复刻老式国内炒股软件的操作和信息密度**。
- 算法研究与实现使用 **GPT-6 Astra 子代理**；其他子代理仅用 **GPT-6.1 Sol 或 Terra**。
- 先创建 Git 仓库，每完成一个功能提交一次。仓库为当前目录，分支 `codex/stock-simulator`。

## 产品目标

让玩家打开浏览器就能以散户的方式看行情、读新闻、下限价单、撤单、看持仓，在连续演化的市场中体验盈亏。价格由市场状态与不同交易者行为共同形成，而非每个格子独立抽随机数。界面像国内 PC 行情交易终端，游戏时间融入工具栏。

## 方案比较

1. **拟真生成市场（用户选择）**：虚构公司＋真实制度，离线运行、时间加速、可复盘；无法等同于真实交易所或真实证券价格。
2. 历史回放：走势来自真实历史，但需要可靠历史数据、复权与时间一致性处理，新闻与玩家冲击也难以同步。
3. 实时模拟盘：现实行情容易理解，但依赖数据授权、网络与真实交易时间，不适合连续游戏。

## 第一版范围（以下细节为实现方建议）

### 市场与账户

- 12 家原创虚构公司，分属金融、消费、能源、科技、医药、制造等行业。仅模拟沪市主板普通股票，不混入科创板、创业板、ST 等不同规则。
- 默认种子可复现；生成至少 60 个交易日的日 K 历史，当前交易日从开盘后开始，让第一屏有可读走势。初始日期建议 2026-11-09。
- 账户初始现金 5000 元、无持仓。金额与价格使用整数分保存，界面显示元。
- 100 股整数倍买入、T+1 可卖、普通股前收盘价上下 10% 限价，限价单、五档盘口、部分成交、资金/持仓冻结、撤单、当日订单收盘过期。
- 交易费用作为明确展示的游戏参数：默认佣金万 2.5、每笔最低 5 元，卖出印花税万 5、过户费十万分之一（按已查权威规则核实）。最低佣金按整张订单累计成交补足，避免分笔重复扣费。
- 真实连续竞价时段 09:30–11:30 / 13:00–15:00；首版不实现集合竞价、盘后定价交易、融资融券、分红除权、公司行动。午休明确呈现并可跳过，收盘可进入下一交易日；周末跳过，法定节假日历不在首版范围。

### 自动化市场算法

- Astra 负责完整市场算法、交易账户规则及其测试；主代理仅做 API 适配与 UI，不以其他模型替换算法。
- 种子随机数；宏观与行业共同因子；公司基本面；波动率状态；基本面、趋势、噪声、流动性提供者等异质交易者；订单簿撮合价格发现；随机但具有行业/公司因果影响的模拟新闻。
- 内部时间步与 UI 刷新解耦，可暂停、继续、选择速度与推进下一交易日。高倍速批处理，避免定时器堆积。
- 明确研究启发与游戏简化的差别，不声称经实盘校准或能够预测真实股价。研究说明及来源保存在 `docs/market-model.md`。

### 界面

- 原创品牌「股海证券 / StockSim」，黑色底、红涨绿跌、黄色代码和关键数值、细灰蓝边框、蓝色选择条、紧凑工具栏；不用大卡片营销页面。
- 顶部：菜单、行情导航、模拟日期与时间、运行/暂停、倍速、下一日、设置入口；下面为模拟市场指数摘要。
- 左：可排序行情/自选表，名称/代码/现价/涨跌幅/成交量；搜索按代码、中文名称过滤，点击同步图表与下单标的。
- 中：股票名称、当前价与 OHLC/量额等摘要；分时/日 K 切换；分时均价、K线均线与成交量；可缩放、十字光标、悬停数据。
- 右：真实五档买卖盘、最新成交、买入/卖出表单，限价与数量输入，1/4、1/2、全仓数量快捷键，费用/可买可卖提示，订单结果反馈。
- 下方：持仓、当日委托、成交记录、市场快讯标签；资产/现金/市值/浮动盈亏摘要。撤单、持仓选股、新闻与行情相互关联。
- 状态栏：当前市场阶段、连接为“本地模拟引擎”、快捷键及存档状态。明显但克制地标注模拟市场。
- 桌面为优先目标，1440×900 和 1920×1080 完整体验；窄屏采用可切换区域与滚动，不缩成难读的微型桌面。

### 存档与设置

- 自动本地存档，刷新恢复；导出/导入 JSON 存档，结构校验及版本号；新开局需要确认。
- 设置内说明规则、费率、模型来源、操作方法。没有真实开户、真实资金、登录或付费流程。
- UI 偏好与速度可保存；导入坏文件给出明确错误，旧档不能静默覆盖。

## 技术与模块边界

- React＋TypeScript＋Vite，HTML5 Canvas 图表（ECharts），Zustand，TanStack Table，Radix Dialog，Lucide 图标，Zod 数据校验，date-fns；Vitest 验证算法与交易账本，Playwright/浏览器验证关键交互。
- `src/engine/`：Astra 独占市场模型、类型、数据、账户撮合、研究和测试。预期 `createMarket({seed,startingCash})`、`step(...)`、`placeOrder(...)`、`cancelOrder(...)`、`getSnapshot()`、`exportState()/importState()`，精确类型由 Astra 固定后统一。
- `src/store/`：引擎生命周期、状态发布、存档、时间控制。
- `src/components/`：行情表、图表、盘口、交易表单、账户与新闻、设置对话框。
- `src/styles/`：终端风格、布局和响应式。
- 使用用户给定的当前 checkout。第一版优先本地开发/预览，是否托管发布留到可运行版本后决定。

## 验收

1. `npm install` 后 `npm run dev` 可玩；`npm run build` 成功。
2. 首屏显示 5000 元可用资金、模拟行情、图表和盘口，时间自动推进；暂停与倍速有效。
3. 低价股票买单可成交；资金、佣金、持仓与冻结资金正确；不足资金/非法数量被拒绝。
4. 当日买入不能当日卖，下一交易日释放可卖；撤单释放冻结资金，重复撤单不会造钱。
5. 同种子和命令可复现；价格限幅、整数金额、订单与库存守恒经测试。
6. 刷新恢复，合法导入/导出可还原，损坏存档有错误提示；浏览器控制台无未处理异常。
7. 每个独立完成功能有 Git commit；交付启动方式、模型说明和已知简化。
