# 玩家排行榜与个人战绩

已获用户同意实施。沿用黑色终端，不调整共享市场、撮合、行情随机源或存档 schema 5。

## 行为与口径

- 新增「玩家战绩」工作区，内含本人战绩与服务器排行榜；离开后交易草稿仍保留。
- 本人可看资产曲线、累计盈亏与收益率、近 5 日收益、观察最大回撤、成交笔数、累计费用、最佳及最差完整交易日。
- 初始本金仍为 5000 元。累计指标从真实入场时刻开始，成交笔数来自持久化累计计数，不依赖截断后的交易列表。
- 近 5 日按全服当前交易日至前 4 日的开盘区间计算。实际覆盖不足时显示覆盖信息，该排序不给名次；不补造历史。
- 最大回撤仅针对当前保留的最多 30 个交易日观察数据，展示起止时间及压缩提示；不称为终身回撤。
- 最佳和最差交易日仅使用已收盘且完整的记录；没有合格记录时为空。
- 排行榜支持累计收益率、近 5 日收益率、观察最大回撤排序。相同指标竞争排名，例如 1、1、3；不可用指标后置且名次为空。

## 隐私与持久化

- 所有新旧账户默认不上榜。本人明确开启后，公开昵称、入场时间、收益率与回撤及其覆盖信息。
- 榜单不返回现金、资产金额、持仓、订单、成交或私人曲线。管理员也通过同一玩家接口参与。
- SQLite 新增独立偏好表，缺行等同关闭。退出和封禁后服务器查询立即剔除；其他打开的榜单每 5 秒刷新。
- 修改偏好与全局 revision/savedAt 同事务提交，失败保持原状态。重复写同值不推进 revision。
- 私人接口只能返回当前认证用户；沿用 CSRF、身份校验、断线清理和取消旧请求。
- 管理员备份升级为 schema 2 并包含上榜偏好，游戏引擎 schema 不变。

## 实现分工与验证

算法由 GPT-6 Astra 编写；Go HTTP/SQLite 与 React UI 分别由 GPT-6.1 Sol、Terra 实现。根代理负责原生 HTTP 集成、浏览器验收、分功能提交与推送。覆盖短历史、截断计数、并列排名、旧库迁移、事务失败、退出/封禁/身份变化与过期响应。使用临时数据库验证，保留用户正在玩的存档。
